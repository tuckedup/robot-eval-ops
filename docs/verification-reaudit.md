# Independent re-audit of the audit fixes

A fresh agent that did not write the fixes attacked commit `ca3601a` (read-only on `src/`, `tests/`, `docs/`, `data/`;
databases opened as copies). It recomputed the headline numbers, the stress-study accounting and the real-data hashes,
and probed each fix. Dispositions below; "fixed" means a regression test was added (see `docs/audit-remediation.md`).

| Sev | Finding | Disposition |
|---|---|---|
| P2 | A1: a QA report with `accepted=False` but no error flag (e.g. duration under 1 s, no outcome label) still became `quality=pass` and a verified success | **Fixed**: such a report is at best `flagged`, never `pass` (`tests/core/test_qa_fail_closed.py::test_rejected_report_without_error_flag_is_never_pass`). Note: `flagged` is still an accepted state for verified success; a recording-integrity problem must carry an error flag, as every integrity check already does |
| P2 | A2: orphan rows for an unlisted episode, extra or garbage shards were accepted | **Fixed**: shard-level checks (unlisted-episode rows, unreferenced shards, row totals) |
| P2 | A2: timestamps offset by +5 s / +1000 s, string/bool-typed state, action and timestamp, and a missing `index` column were accepted | **Fixed**: timestamps must start at 0 per episode; state/action must be lists of float/int; timestamp/index columns numeric; `index` required when ranges are declared |
| P2 | A3: hardware recording still copied the first camera's whole shared MP4 | **Fixed**: `extract_episode_video` re-encodes only the recorded episode's window for one camera (`tests/robotics/test_robotics_hardware.py::test_recording_uses_only_the_recorded_episodes_camera_frames_from_a_v3_dataset`); extraction failure is a recording failure |
| P2 | Resume bullet said one controller fails at 2 kg and the other at 35 mm (both fail at 35 mm) | **Fixed** in `docs/resume-evidence.md` |
| P2 | "Where the time goes" table was labelled nominal but used another scenario | **Fixed**: uses the nominal start; regenerated |
| P3 | `verification-run.json` stale (older commit, one ruff error) | **Fixed**: regenerated by `scripts/verify_all.sh` on the final commit (see file) |
| P3 | Missing `docs/verification-reaudit.md` | this file |
| P3 | `study` default protocol path is repo-relative; misleading error from a wheel | **Fixed**: explicit "protocol file not found: ... (pass --protocol)" |
| P3 | `lerobot-replay` unguarded | **Fixed**: replay goes through the guard; `lerobot-calibrate` stays API-only dry-run |
| P3 | Lease aliasing (`COM3:`, `//./COM3`), per-database scope, crash before RUNNING not auto-found | aliasing **fixed** and tested; the lease is per database (a different `--home` does not collide) and a pre-RUNNING crash needs `session recover <id>`: **documented, not changed** |
